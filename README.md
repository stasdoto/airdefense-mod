# Stasdoto Air Defense — ракеты и ПВО для Minecraft

Мод для **Minecraft Java 26.3** (Fabric). Пусковые установки «Искандер-М», крылатых ракет, дронов «Шахед», HIMARS и системы ПВО Patriot, IRIS-T SLM, NASAMS, Gepard и ПЗРК Stinger. Ракеты летают по настоящим профилям (баллистическая дуга, полёт над рельефом, медленный дрон), ПВО само находит цели и сбивает их, взрывы с воронкой, обломками, огнём, дымом и ударной волной.

## Что внутри

| Удар | Как летит |
|---|---|
| «Искандер-М» | вертикальный старт, высокая баллистическая дуга, почти отвесное падение, самая мощная боевая часть |
| Крылатая ракета «Калибр» | ускоритель, потом низко над землёй огибая холмы, в конце пикирует |
| «Шахед-136» | медленный, гудит как мопед, слегка виляет, залп из 5 штук, поджигает |
| HIMARS | залп 6 ракет GMLRS по пологой дуге |

| ПВО | Чем хороша |
|---|---|
| Patriot | дальность 220 блоков, лучше всех сбивает баллистику, по «Искандеру» пускает 2 ракеты |
| IRIS-T SLM | 140 блоков, очень хорошо по крылатым ракетам и дронам |
| NASAMS | 120 блоков, по крылатым и дронам |
| Gepard | зенитные пушки с трассерами, 64 блока, лучше всего по дронам |
| ПЗРК Stinger | в руку: навёл на ракету или дрон, ПКМ — пуск |

Перехват не гарантирован: у каждой ракеты ПВО свой шанс поражения по разным целям (например, Stinger почти не может сбить «Искандер», а Patriot — может).

## Как играть

1. Возьми **Планшет целеуказания** и нажми ПКМ, глядя туда, куда нужно ударить (до 600 блоков, если там всё прогружено). Для дальних целей: держа планшет, напиши `/ad target X Y Z`.
2. Поставь пусковую установку и нажми по ней ПКМ планшетом — пуск. Пустая рука по пусковой — показать статус.
3. Поставь ПВО — оно включено сразу, само ищет цели и стреляет. ПКМ пустой рукой — включить/выключить, Shift+ПКМ — статус.
4. Редстоун-сигнал на пусковую повторяет последний удар.

Мод ломает блоки взрывами так же, как динамит. Если отключить взрывы динамита в правилах мира, воронок не будет.

## Установка (Mac, проще всего через Modrinth App)

1. Скачай и установи бесплатное приложение **Modrinth App**: https://modrinth.com/app
2. В нём создай новую сборку: **+ → Fabric → версия 26.3**.
3. В сборке нажми **Add content → Mods**, найди **Fabric API** и установи.
4. Там же нажми **Add from file** и выбери файл `airdefense-…jar` из этого мода.
5. Нажми **Play**. Вкладка мода в творческом режиме называется **«Ракеты и ПВО»**.

Через обычный лаунчер Minecraft тоже можно: поставь Fabric Loader 0.19.5 для 26.3 (https://fabricmc.net/use/installer), затем положи в папку `mods` файл мода и **Fabric API** для 26.3.

## Шейдеры (по желанию, для самой красивой картинки)

Эффекты мода сделаны из мягких частиц: инверсионные следы, огненные шары, столбы дыма, светящиеся факелы двигателей. Они хорошо выглядят и без шейдеров, а с шейдерами получают реалистичный свет, свечение (bloom) и атмосферный туман.

1. В Modrinth App открой свою сборку → **Add content → Mods** → найди **Iris Shaders** и установи (приложение само добавит Sodium).
2. Там же **Add content → Shaders** → найди **Complementary Shaders – Reimagined** и установи.
3. В игре: **Настройки → Графика → Пакеты шейдеров** → выбери Complementary.
4. Если на Mac подтормаживает, в настройках шейдера выбери профиль пониже (Medium/Low).

## Сборка из исходников

GitHub Actions собирает мод при каждом изменении. Локально: `./gradlew build`, готовый файл в `build/libs/`.
